# SepiaDoc releases

Official installers for **SepiaDoc**, the PDF app by Mako Logics LLC: read, edit, fill and sign
PDFs. Free for personal use, affordable for business, and private.

Download the latest `SepiaDoc-Setup-<version>.exe` from the
[Releases](https://github.com/MakoBytes-com/sepiadoc-releases/releases/latest) page. Every
installer is signed by **Mako Logics LLC**; Windows shows that name when you run it. SepiaDoc's
own **Check for updates** (Help ▸ About) installs a new release only after confirming that
signature.
